# Archived notebooks

Sandbox, conference (COSI), system analysis, learning and acquisition notebooks from development. Kept for reference only.

These are not maintained and most will not run as-is: they import `libwallerlab` (not in this repo), use hardcoded paths on the authors' machines, and some select the arrayfire backend. `publications_old/` holds superseded figure notebooks; `fig_fom_2019_toplevel.ipynb` is an earlier copy of `notebooks/publications/fig_fom_2019.ipynb` that was at the top of `notebooks/`.
